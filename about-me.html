Projects

CAPSTONE PROJECT

KLIR: An IoT-Based Toilet Sanitation, Analytics, and Predictive Maintenance Management System

KLIR is an integrated IoT sanitation and custodial management system that connects automated restroom hardware with real-time cloud telemetry, a web operations dashboard, and a cross-platform mobile custodial application across a 22-restroom campus directory.

Current features

  • Touchless 7-state ESP32 automation for ultrasonic occupancy detection, motorized lid control, automatic flushing, and occupancy-interlocked UV-C disinfection.
  • Real-time water flow telemetry, usage analytics, continuous-flow leak detection, and public QR code stall issue reporting.
  • Role-based web dashboard and mobile app with automated cleaning dispatch, 10-point custodial checklists, before-and-after photo proof, biometric login, and supervisor QA audits.

Technology: TypeScript, Next.js, React Native (Expo), Kotlin, C++ / Arduino (ESP32), Tailwind CSS, Firebase (Auth, Firestore, Storage, FCM), HiveMQ Cloud (MQTT over TLS), XML, Gradle, Vercel, and Railway.
